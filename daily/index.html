Start agents from events, not a chat box.

Mar de Haym laid out the six layers of a working agentic system.

It's a production blueprint. Keep run state in Postgres so a run can resume. Put the guarantees in unit-tested tools, not the prompt. Give each domain its own scoped context. Test against a golden set with a human approval gate. Send every model call through one LLM gateway. It's very bookmarkable: 2.5k likes and about 9.1k bookmarks.

An Elo he puts at 3533, for about $50 of compute.

Deedy Das built Chatarunga, an open-source Rust chess engine.

He used Fable, Neon and Astra plus Modal (204 likes). The useful part is his lessons: always define a minimum viable run first, use Rust's compiler and tests as guardrails, keep a single paper.pdf as the ground truth for experiments, and act as the agents' scheduler.
